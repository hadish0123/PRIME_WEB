# PRIME Browser Engine

مرورگر اختصاصی افزونه **PRIME Browser Operator**. این سرویس یک Chromium ایزوله برای هر نشست می‌سازد و ورود، مشاهده صفحه، کلیک، تایپ و انتخاب را از طریق API خصوصی انجام می‌دهد.

## امنیت

- فقط URLهای عمومی HTTPS پذیرفته می‌شوند.
- درخواست به شبکه‌های محلی و IPهای خصوصی مسدود است.
- نام کاربری و رمز فقط در حافظه همان نشست استفاده می‌شوند و در پاسخ‌ها یا لاگ‌ها قرار نمی‌گیرند.
- هر نشست حداکثر ۱۵ دقیقه عمر دارد و Context مرورگر آن هنگام پایان حذف می‌شود.
- دکمه‌های تغییردهنده با جریان تأیید دومرحله‌ای محافظت می‌شوند.
- تمام APIهای عملیاتی با `BROWSER_ENGINE_TOKEN` محافظت می‌شوند.

## متغیرهای Railway

| متغیر | کاربرد |
| --- | --- |
| `BROWSER_ENGINE_TOKEN` | کلید مشترک حداقل ۳۲ کاراکتری |
| `MAX_SESSIONS` | سقف نشست هم‌زمان؛ پیش‌فرض ۳ |
| `SESSION_TTL_MS` | عمر نشست؛ پیش‌فرض ۹۰۰۰۰۰ میلی‌ثانیه |
| `LOGIN_FORM_WAIT_MS` | مهلت انتظار برای ظاهرشدن فرم ورود؛ پیش‌فرض ۳۰۰۰۰ میلی‌ثانیه |

کلیدها را فقط در Variables سرویس نگه دارید و هرگز داخل Git commit نکنید.
